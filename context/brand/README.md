# brand/ — Activos oficiales de la marca

Aquí van los archivos **propios** de la marca. Las inspiraciones de otras tiendas van en `../references/visual/`.

```text
brand/
  logo/          Logo en SVG (preferido) y PNG transparente; variantes claro/oscuro, isotipo
  fonts/         Archivos de fuente (woff2) + licencia de uso web
  manual/        Manual de marca o guía de estilo (PDF)
  product/       Fotografía oficial de producto (fondo limpio, alta resolución)
  lifestyle/     Fotografía lifestyle o de campaña aprobada
```

Crea solo las subcarpetas que tengas. Usa nombres descriptivos: `logo-horizontal-negro.svg`, `producto-sabor-x-frontal.png`.
